# Standardanimationen / Default motions

27 distinct full-body VRMA clips selected from the Overte-derived Hanami library (Apache-2.0). See NOTICE.md, LICENSE-Apache-2.0.txt and LICENSES.json.

Welcome uses a short acknowledgement nod, listening a calm idle, shy a head tilt and joy applause. Laugh and surprise do not have dedicated body clips; the face and current base motion provide the reaction. Additional user VRMA assignments remain possible. Personal reference packs take precedence.
